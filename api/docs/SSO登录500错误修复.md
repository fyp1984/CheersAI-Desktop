# SSO 登录 500 错误修复

## 问题描述

用户在 SSO 登录时遇到 500 INTERNAL SERVER ERROR 错误。

## 根本原因

在 `desktop_sso.py` 中，FileBay 自动配置代码存在两个问题：

### 问题 1: 错误的属性访问方式

```python
# ❌ 错误的代码
custom_config = account.custom_config_dict if account.custom_config else {}
```

这行代码是多余的，因为 `custom_config_dict` 属性已经处理了 `None` 的情况：

```python
# Account 模型中的定义
@property
def custom_config_dict(self) -> dict[str, Any]:
    return json.loads(self.custom_config) if self.custom_config else {}
```

### 问题 2: 保存配置时使用了错误的属性

在 `filebay_config_service.py` 的 `_save_config_to_account` 函数中：

```python
# ❌ 错误的代码
def _save_config_to_account(email: str, config: dict):
    account = db.session.query(Account).filter_by(email=email).first()
    if account:
        account.custom_config = config  # 应该使用 custom_config_dict
        db.session.commit()
```

`custom_config` 是一个 JSON 字符串字段，不能直接赋值字典。应该使用 `custom_config_dict` 属性的 setter。

## 修复方案

### 修复 1: 简化属性访问

**文件**: `api/controllers/console/auth/desktop_sso.py`

```python
# ✅ 修复后的代码
custom_config = account.custom_config_dict
```

直接使用 `custom_config_dict` 属性，它会自动处理 `None` 的情况并返回空字典。

### 修复 2: 使用正确的属性 setter

**文件**: `api/services/filebay_config_service.py`

```python
# ✅ 修复后的代码
def _save_config_to_account(email: str, config: dict):
    """保存配置到账号"""
    account = db.session.query(Account).filter_by(email=email).first()
    if account:
        account.custom_config_dict = config  # 使用 custom_config_dict setter
        db.session.commit()
```

使用 `custom_config_dict` setter，它会自动将字典转换为 JSON 字符串。

## 技术细节

### custom_config_dict 属性实现

```python
class Account(UserMixin, TypeBase):
    # ...
    custom_config: Mapped[str | None] = mapped_column(LongText, default=None)
    
    @property
    def custom_config_dict(self) -> dict[str, Any]:
        return json.loads(self.custom_config) if self.custom_config else {}

    @custom_config_dict.setter
    def custom_config_dict(self, value: dict[str, Any]) -> None:
        self.custom_config = json.dumps(value)
```

这个属性提供了：
- **Getter**: 自动将 JSON 字符串解析为字典，如果为 None 则返回空字典
- **Setter**: 自动将字典序列化为 JSON 字符串

## 注意事项

1. **始终使用 `custom_config_dict` 属性**，不要直接访问 `custom_config` 字段
2. **不需要手动检查 `None`**，属性的 getter 已经处理了
3. **Flask 会自动重载**，修改后无需手动重启
