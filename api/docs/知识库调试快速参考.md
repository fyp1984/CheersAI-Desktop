# 知识库调试快速参考

## 🚀 快速命令

### 使用统一工具（推荐）

```bash
cd api

# 查看摘要（最常用）
python tools/knowledge_base_tools.py summary --dataset-id <your-id>

# 查看状态统计
python tools/knowledge_base_tools.py status --dataset-id <your-id>

# 查看文档详情
python tools/knowledge_base_tools.py details --dataset-id <your-id>

# 查看错误文档
python tools/knowledge_base_tools.py errors --dataset-id <your-id>

# 重置错误文档
python tools/knowledge_base_tools.py reset --dataset-id <your-id>

# 查看等待处理的文档
python tools/knowledge_base_tools.py waiting --dataset-id <your-id>
```

### 使用独立脚本（快速）

```bash
cd api

# 快速查看状态
python check_status_counts.py

# 查看所有文档
python check_doc_details.py

# 重置错误文档
python reset_all_errors.py
```

---

## 📊 文档状态说明

| 状态 | 说明 | 处理建议 |
|------|------|---------|
| `waiting` | 等待处理 | 正常，会自动处理 |
| `indexing` | 正在处理 | 正常，等待完成 |
| `completed` | 处理成功 | 无需操作 |
| `error` | 处理失败 | 查看错误信息，重置后重试 |

## 🐛 故障排查

### 问题：文档一直 waiting

```bash
# 1. 检查是否缺少处理规则
python tools/knowledge_base_tools.py waiting --dataset-id <your-id>

# 2. 检查 Celery Worker
ps aux | grep celery

# 3. 查看 Celery 日志
# 查看终端输出或日志文件
```

### 问题：文档处理失败

```bash
# 1. 查看错误信息
python tools/knowledge_base_tools.py errors --dataset-id <your-id>

# 2. 检查服务状态
docker ps | grep -E "unstructured|plugin"

# 3. 查看服务日志
docker logs docker-plugin_daemon-1 --tail 50
docker logs docker-unstructured-1 --tail 50
```

### 问题：批量文档失败

```bash
# 1. 查看失败数量
python tools/knowledge_base_tools.py status --dataset-id <your-id>

# 2. 批量重置
python tools/knowledge_base_tools.py reset --dataset-id <your-id> --yes

# 3. 检查服务配置
docker exec docker-plugin_daemon-1 env | grep UNSTRUCTURED
```

## 📝 服务管理

### 检查服务状态

```bash
# Docker 服务
cd docker
docker-compose -f docker-compose.middleware.yaml ps

# 检查特定服务
docker ps | grep -E "plugin|unstructured|postgres|redis"
```

### 重启服务

```bash
cd docker

# 重启 Plugin Daemon
docker-compose -f docker-compose.middleware.yaml restart plugin_daemon

# 重启 Unstructured
docker-compose -f docker-compose.middleware.yaml restart unstructured

# 重启所有中间件
docker-compose -f docker-compose.middleware.yaml restart
```

### 查看日志

```bash
# Plugin Daemon 日志
docker logs docker-plugin_daemon-1 --tail 100 -f

# Unstructured 日志
docker logs docker-unstructured-1 --tail 100 -f

# Celery Worker 日志
# 查看运行 Celery 的终端输出
```

## 🔍 高级查询

### 直接查询数据库

```bash
# 连接数据库
psql -h 127.0.0.1 -U postgres -d dify

# 查询文档状态
SELECT indexing_status, COUNT(*) 
FROM documents 
WHERE dataset_id = '<your-id>' 
GROUP BY indexing_status;

# 查询错误文档
SELECT name, error, created_at 
FROM documents 
WHERE dataset_id = '<your-id>' 
AND indexing_status = 'error' 
ORDER BY created_at DESC 
LIMIT 5;

# 查询处理规则
SELECT id, mode, rules 
FROM dataset_process_rules 
WHERE dataset_id = '<your-id>' 
ORDER BY created_at DESC 
LIMIT 1;
```
