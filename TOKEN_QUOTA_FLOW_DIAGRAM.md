## 📈 配额检查详细流程

```
check_quota(tenant_id, user_id, tokens_to_use)
        │
        ▼
┌─────────────────────────────────────────┐
│  1. 获取激活的配额配置                    │
│  get_active_quota_config()              │
│                                         │
│  查询优先级:                             │
│  • 用户级配置 (user_id 匹配)             │
│  • 租户级配置 (user_id = NULL)          │
│  • 按 priority 降序排序                 │
└─────────────────────────────────────────┘
        │
        ▼
    找到配额配置？
        │
        ├─── NO ────────────────────────┐
        │                               │
        │                               ▼
        │                    ┌──────────────────┐
        │                    │ 返回无限制        │
        │                    │ within_quota=true│
        │                    │ should_use_local │
        │                    │ =false           │
        │                    └──────────────────┘
        │
        ▼
┌─────────────────────────────────────────┐
│  2. 获取当前时间窗口的使用记录            │
│  get_current_period_usage()             │
│                                         │
│  计算时间窗口:                           │
│  • hourly: 当前小时                     │
│  • daily: 当前天                        │
│  • weekly: 当前周                       │
│  • monthly: 当前月                      │
│  • custom: 自定义间隔                   │
└─────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────┐
│  3. 计算剩余配额                         │
│                                         │
│  remaining_tokens =                     │
│    token_limit - total_tokens           │
│                                         │
│  within_quota =                         │
│    remaining_tokens >= tokens_to_use    │
│                                         │
│  should_use_local =                     │
│    !within_quota || is_exceeded         │
└─────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────┐
│  4. 返回检查结果                         │
│  {                                      │
│    "within_quota": bool,                │
│    "remaining_tokens": int,             │
│    "should_use_local": bool,            │
│    "quota_config": {...},               │
│    "current_usage": {...}               │
│  }                                      │
└─────────────────────────────────────────┘
```

## 📝 记录使用详细流程

```
record_token_usage(tenant_id, model_provider, model_name, tokens_used)
        │
        ▼
┌─────────────────────────────────────────┐
│  1. 获取激活的配额配置                    │
│  get_active_quota_config()              │
└─────────────────────────────────────────┘
        │
        ▼
    找到配额配置？
        │
        ├─── NO ────────────────────────┐
        │                               │
        │                               ▼
        │                    ┌──────────────────┐
        │                    │ 不记录，直接返回  │
        │                    │ return None      │
        │                    └──────────────────┘
        │
        ▼
┌─────────────────────────────────────────┐
│  2. 获取当前时间窗口的使用记录            │
│  get_current_period_usage()             │
└─────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────┐
│  3. 更新使用记录                         │
│                                         │
│  • total_tokens += tokens_used          │
│  • input_tokens += input_tokens         │
│  • output_tokens += output_tokens       │
│  • request_count += 1                   │
│  • model_usage_details[model] += ...    │
└─────────────────────────────────────────┘
        │
        ▼
    是否超额？
    (total_tokens >= token_limit)
        │
        ├─── YES ──────────────────────┐
        │                              │
        │                              ▼
        │                   ┌──────────────────┐
        │                   │ 标记为已超额      │
        │                   │ is_exceeded=true │
        │                   │ exceeded_at=now  │
        │                   └──────────────────┘
        │                              │
        └──────────────┬───────────────┘
                       │
                       ▼
        ┌─────────────────────────────────────────┐
        │  4. 创建日志记录                         │
        │  TokenQuotaLog                          │
        │                                         │
        │  • usage_id                             │
        │  • model_provider                       │
        │  • model_name                           │
        │  • tokens_used                          │
        │  • tokens_before                        │
        │  • tokens_after                         │
        │  • is_within_quota                      │
        │  • switched_to_local                    │
        └─────────────────────────────────────────┘
                       │
                       ▼
        ┌─────────────────────────────────────────┐
        │  5. 提交到数据库                         │
        │  db.session.commit()                    │
        └─────────────────────────────────────────┘
                       │
                       ▼
        ┌─────────────────────────────────────────┐
        │  6. 返回日志记录                         │
        │  return TokenQuotaLog                   │
        └─────────────────────────────────────────┘
```

## 🕐 时间窗口计算示例

### Daily (每天)
```
当前时间: 2026-05-09 15:30:00

period_start: 2026-05-09 00:00:00
period_end:   2026-05-10 00:00:00

时间窗口: 24 小时
```

### Hourly (每小时)
```
当前时间: 2026-05-09 15:30:00

period_start: 2026-05-09 15:00:00
period_end:   2026-05-09 16:00:00

时间窗口: 1 小时
```

### Weekly (每周)
```
当前时间: 2026-05-09 (周六) 15:30:00

period_start: 2026-05-04 (周一) 00:00:00
period_end:   2026-05-11 (周一) 00:00:00

时间窗口: 7 天
```

### Monthly (每月)
```
当前时间: 2026-05-09 15:30:00

period_start: 2026-05-01 00:00:00
period_end:   2026-06-01 00:00:00

时间窗口: 1 个月
```

### Custom (自定义 - 6小时)
```
当前时间: 2026-05-09 15:30:00
interval_value: 21600 秒 (6小时)

计算:
seconds_since_epoch = 1778529000
period_index = 1778529000 / 21600 = 82338
period_start = epoch + (82338 * 21600) = 2026-05-09 12:00:00
period_end = period_start + 21600 = 2026-05-09 18:00:00

时间窗口: 6 小时
```

## 📈 统计查询流程

```
get_quota_statistics(tenant_id, start_date, end_date)
       │
       ▼
┌─────────────────────────────────────────┐
│ 1. 查询时间范围内的所有使用记录          │
│    TokenQuotaUsage                      │
│    WHERE period_start >= start_date     │
│      AND period_end <= end_date         │
└─────────────────────────────────────────┘
       │
       ▼
┌─────────────────────────────────────────┐
│ 2. 聚合统计                              │
│                                         │
│ • total_tokens = SUM(total_tokens)      │
│ • total_requests = SUM(request_count)   │
│ • exceeded_periods = COUNT(is_exceeded) │
└─────────────────────────────────────────┘
       │
       ▼
┌─────────────────────────────────────────┐
│ 3. 按模型分类统计                        │
│                                         │
│ model_statistics = {                    │
│   "openai/gpt-4": {                     │
│     "tokens": 150000,                   │
│     "requests": 300                     │
│   },                                    │
│   "ollama/llama2": {                    │
│     "tokens": 50000,                    │
│     "requests": 100                     │
│   }                                     │
│ }                                       │
└─────────────────────────────────────────┘
       │
       ▼
┌─────────────────────────────────────────┐
│ 4. 返回统计结果                          │
└─────────────────────────────────────────┘
```

## 🎯 总结

这些流程图展示了 Token 配额系统的：

1. **系统架构** - 从数据库到应用层的完整架构
2. **LLM 调用流程** - 如何在调用前检查配额，调用后记录使用
3. **配额检查流程** - 详细的配额检查逻辑
4. **记录使用流程** - 如何记录和更新 Token 使用
5. **时间窗口计算** - 不同时间间隔的计算方式
6. **模型选择决策** - 如何根据配额选择模型
7. **数据流** - 完整的数据流向
8. **配额重置** - 自动和手动重置机制
9. **统计查询** - 如何生成使用统计

这些流程图可以帮助你更好地理解系统的工作原理，并指导集成工作。
