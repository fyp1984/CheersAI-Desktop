│ 🎯 快速开始                                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

  1. 安装依赖:
     $ pip install -r requirements.txt

  2. 运行测试:
     $ python test_plugin.py

  3. 打包插件:
     $ bash deploy.sh

  4. 上传到 Dify:
     - 登录 Dify 管理后台
     - 进入插件管理
     - 上传 .difypkg 文件
     - 启用插件

  5. 开始使用:
     - 在工作流中添加工具
     - 选择 file-format-converter/word_export
     - 配置参数并运行

└──────────────────────────────────────────────────────────────────────────────┘

  在 Dify 工作流中使用:

  steps:
    - name: 导出 Word 文档
      type: tool
      tool: file-format-converter/word_export
      inputs:
        markdown_content: "# 标题\n\n内容..."
        document_name: "我的文档"
