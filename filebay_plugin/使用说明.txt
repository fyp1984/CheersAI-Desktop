================================================================================
                          快速安装步骤
================================================================================

第一步：安装 Dify 插件开发工具
----------------------------------------
# macOS ARM64
curl -L https://github.com/langgenius/dify-plugin-daemon/releases/latest/download/dify-plugin-darwin-arm64 -o dify
chmod +x dify
sudo mv dify /usr/local/bin/

# Windows
下载 dify-plugin-windows-amd64.exe 并重命名为 dify.exe


第二步：打包插件
----------------------------------------
cd filebay_plugin
dify plugin package .

# 将生成 filebay_plugin.difypkg 文件


第三步：安装到 Dify
----------------------------------------
1. 打开 Dify 管理后台
2. 进入"工作空间设置" → "插件"
3. 点击"安装插件"
4. 上传 filebay_plugin.difypkg
5. 等待安装完成


第四步：配置插件
----------------------------------------
在插件列表中找到"FileBay Sync"，点击配置：

FileBay URL: https://uat-filebay.cheersai.cloud
Access Token: [从 FileBay 设置中生成]
Repository Owner: your-username
Repository Name: workspace
Branch Name: main

点击"验证" → "保存"


第五步：开始使用
----------------------------------------
创建 Agent 应用，启用 FileBay Sync 插件，然后：

示例对话 1：
用户: 请列出仓库中的所有文件
Agent: [自动调用 list_files 工具]

示例对话 2：
用户: 读取 README.md 文件
Agent: [自动调用 read_file 工具]

示例对话 3：
用户: 创建文件 test.txt，内容是 "Hello Dify!"
Agent: [自动调用 write_file 工具]

================================================================================
                          插件功能说明
================================================================================

✅ read_file - 读取文件
   - 从 FileBay 仓库读取任意文件
   - 支持文本文件（UTF-8, GBK 等）
   - 支持二进制文件（Base64 编码）

✅ write_file - 写入文件
   - 创建新文件或更新现有文件
   - 自动处理版本控制
   - 可自定义提交信息

✅ list_files - 列出文件
   - 浏览目录结构
   - 显示文件信息
   - 支持递归列表

================================================================================
                          常见问题
================================================================================

Q: 如何获取 FileBay Access Token？
A: 登录 FileBay → 设置 → 应用 → 访问令牌 → 生成新令牌
   权限选择：read:repository, write:repository

Q: 插件安装失败怎么办？
A: 1. 检查 Dify 版本（需要 1.0+）
   2. 重新打包插件
   3. 查看 Dify 日志

Q: 无法连接到 FileBay？
A: 1. 确认 URL 正确
   2. 检查 Token 有效性
   3. 验证网络连接

Q: 文件读取返回 404？
A: 1. 确认文件路径正确
   2. 使用 list_files 查看目录
   3. 检查分支名称
