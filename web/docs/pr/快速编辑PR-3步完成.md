# 快速编辑 PR - 3 步完成

## 🚀 快速操作（2 分钟）

### 第 1 步：打开 PR
点击页面右上角绿色的 **"View pull request"** 按钮

或直接访问：
```
https://github.com/fyp1984/CheersAI-Desktop/pull/17
```

---

### 第 2 步：编辑标题

1. 找到标题 "V1.2"
2. 点击旁边的 **铅笔图标 ✏️**
3. 改为（复制使用）：
   ```
   feat: Desktop SSO 登录功能集成 (V1.2)
   ```
4. 点击 **"Save"**

---

### 第 3 步：添加描述

1. 找到 "No description provided"
2. 点击右侧的 **三个点 `...`**
3. 选择 **"Edit"**
4. 打开 `PR模板-复制使用.md`，复制 "PR 描述" 部分
5. 粘贴到描述框
6. 点击 **"Update comment"**

---

- ✅ 验证自动通过
- ✅ PR 可以合并
