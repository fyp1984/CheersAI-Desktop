## 🚀 快速开始

### 创建新 PR
1. 阅读 `创建新PR-feat分支.md`
2. 使用 `PR模板-复制使用.md` 中的模板
3. 确保标题符合 Conventional Commits 规范

### 修复 PR 问题
1. 阅读 `PR标题修复指南.md` 了解规范
2. 使用 `快速修复PR.md` 快速修复
3. 参考 `编辑现有PR指南.md` 编辑 PR

## 📖 Conventional Commits 规范

### 常用前缀
- `feat:` - 新功能
- `fix:` - 修复 Bug
- `docs:` - 文档更新
- `style:` - 代码格式
- `refactor:` - 重构
- `test:` - 测试相关
- `chore:` - 构建/工具相关

### 示例
```
feat: Desktop SSO 登录功能集成
fix: 修复 Weaviate 端口冲突
docs: 更新 API 文档
```
