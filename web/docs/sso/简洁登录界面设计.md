# 简洁登录界面设计

**修改时间**: 2026-04-03  
**状态**: ✅ 已完成

---

## 设计概述

根据用户需求，将登录页面改为简洁的居中卡片风格，移除了左侧的宣传内容，只保留核心的登录功能。

### 视觉特点

1. **背景**: 淡灰色渐变 (from-gray-50 to-gray-100)
2. **Logo**: 
   - 位于卡片上方居中
   - 红色边框的正方形容器
   - 白色背景，带阴影
3. **登录卡片**:
   - 白色背景

5. **文字**: 灰色系，层次分明

## 设计细节

### 颜色方案

- **背景**: `bg-gradient-to-br from-gray-50 to-gray-100`
- **卡片**: `bg-white` + `ring-purple-200`
- **Logo 边框**: `border-red-500`
- **主标题**: `text-gray-900`
- **提示文字**: `text-gray-500`
- **链接**: `text-blue-600 hover:text-blue-700`

### 尺寸规格

- **卡片最大宽度**: `max-w-md` (28rem / 448px)
- **Logo 容器**: `h-20 w-20` (5rem / 80px)
- **Logo 图片**: `h-16 w-16` (4rem / 64px)
- **卡片内边距**: `p-8` (2rem / 32px)
- **圆角**: `rounded-2xl` (1rem / 16px)

### 间距

- Logo 与卡片间距: `mb-6` (1.5rem / 24px)
- 标题与按钮间距: `mb-8` (2rem / 32px)
- 按钮与底部提示间距: `mt-6` (1.5rem / 24px)
- 底部提示行间距: `space-y-3` (0.75rem / 12px)

---

## 响应式设计

当前设计在所有屏幕尺寸下都保持居中卡片布局：

- **移动端**: 卡片宽度自适应，保持 `p-4` 外边距
- **桌面端**: 卡片最大宽度 `max-w-md`，居中显示
