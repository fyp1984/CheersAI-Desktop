# SSO 角色权限快速实现说明

## 实现概述

已完成基于 SSO 角色的权限控制核心功能，实现了从 Casdoor 获取用户角色并动态控制前端菜单显示。

**实现日期**: 2026-04-02  
**实现方式**: 快速MVP版本，专注核心功能

---

## 已实现的功能

### 1. 后端角色提取和同步

**文件**: `api/controllers/console/auth/sso_token.py`

**实现内容**:
- 从 SSO userinfo 中提取 `type` 或 `role` 字段
- 角色映射逻辑：
  - `admin`, `owner` → `owner`
  - `technician`, `editor` → `editor`
  - 其他（`user`, `normal`, 空值） → `normal`
- 新用户创建时自动设置工作空间角色
- 现有用户登录时自动更新工作空间角色
- 保护唯一 owner 不被降级

**关键代码**:
```python
# 提取角色信息
sso_role_raw = user_info.get('type') or user_info.get('role') or 'user'
sso_role = sso_role_raw.lower().strip() if sso_role_raw else 'user'

# 映射到系统角色
if sso_role in ['admin', 'owner']:
    system_role = 'owner'
elif sso_role in ['technician', 'editor']:
    system_role = 'editor'
else:
    system_role = 'normal'

# 同步到工作空间
tenant_join.role = system_role
```

### 2. 前端菜单权限控制

**文件**: `web/app/components/header/side-nav/index.tsx`

**实现内容**:
- 根据 `currentWorkspace.role` 动态显示菜单
- 三个角色的菜单配置：
  - **管理员（owner/admin）**: 8个菜单
  - **技术员（editor）**: 7个菜单（无审计日志）
  - **普通用户（normal）**: 5个菜单（无智能体管理、工作流）

**菜单分配**:

| 菜单项 | 管理员 | 技术员 | 普通用户 |
|--------|--------|--------|---------|
| 我的 Agent | ✅ | ✅ | ✅ |
| 对话 | ✅ | ✅ | ✅ |
| 知识库 | ✅ | ✅ | ✅ |
| 智能体管理 | ✅ | ✅ | ❌ |
| 工作流 | ✅ | ✅ | ❌ |
| 应用中心 | ✅ | ✅ | ✅ |
| 探索 | ✅ | ✅ | ✅ |
| 审计日志 | ✅ | ❌ | ❌ |

**关键代码**:
```typescript
const isAdmin = useMemo(() => ['owner', 'admin'].includes(currentWorkspace.role), [currentWorkspace.role])
const isEditor = useMemo(() => ['owner', 'admin', 'editor'].includes(currentWorkspace.role), [currentWorkspace.role])

// 智能体管理和工作流 - 仅技术员及以上
if (isEditor) {
  navItems.push({ id: 'plugins', ... })
  navItems.push({ id: 'workflow', ... })
}

// 审计日志 - 仅管理员
if (isAdmin) {
  navItems.push({ id: 'audit-logs', ... })
}
```

## 下一步优化建议

当需要增强安全性和用户体验时，可以按以下顺序实现：

1. **优先级高**：
   - 页面级权限保护（防止直接访问URL）
   - 后端 API 权限验证（防止绕过前端限制）

2. **优先级中**：
   - 按钮级权限控制（优化用户体验）
   - 数据过滤（普通用户只看已发布内容）

3. **优先级低**：
   - 审计日志记录
   - 数据库字段添加
   - 完善的错误处理
