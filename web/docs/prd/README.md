## 🎯 核心功能

### 1. 角色化菜单
根据用户角色（管理员/编辑/成员）显示不同的菜单项

### 2. Vault 浮动按钮
位于客户端右侧边缘，提供快速访问本地数据安全功能

### 3. Agent 中心化
首页聚焦常用 Agent，智能引导脱敏流程

### 4. 权限精细化
成员和编辑仅能设置个人客户端功能，管理员拥有全功能权限
