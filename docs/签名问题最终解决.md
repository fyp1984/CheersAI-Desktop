# ✅ 插件签名验证问题 - 最终解决方案

## 🎯 问题根源

经过全网搜索，找到了正确的解决方案！

关键环境变量是：**`FORCE_VERIFYING_SIGNATURE`** 而不是 `SIGNATURE_VERIFICATION_ENABLED`

## 📚 官方文档参考

根据 Dify 官方文档：
- 文档地址：https://docs.dify.ai/en/develop-plugin/publishing/faq/faq
- 中文文档：https://legacy-docs.dify.ai/zh-hans/plugins/faq

**官方解决方案**：
> Add the field `FORCE_VERIFYING_SIGNATURE=false` to the end of the `/docker/.env` configuration file.

## ✅ 已完成的修复

### 1. 修改 `docker/middleware.env`

```env
# 修改前
FORCE_VERIFYING_SIGNATURE=true

# 修改后
FORCE_VERIFYING_SIGNATURE=false
```

### 2. 修改 `docker-compose.dev.yaml`

在 `plugin_daemon` 服务的环境变量中添加：

```yaml
environment:
  # ... 其他配置
  FORCE_VERIFYING_SIGNATURE: 'false'  # ← 关键配置
```

### 3. 重启服务

```bash
# 停止服务
docker compose -f docker-compose.dev.yaml down

# 重启服务
docker compose -f docker-compose.dev.yaml up -d
```

## 🔍 验证配置

检查环境变量是否生效：

```bash
docker exec dify-plugin-daemon env | grep FORCE_VERIFYING_SIGNATURE
```

应该看到：
```
FORCE_VERIFYING_SIGNATURE=false
```
