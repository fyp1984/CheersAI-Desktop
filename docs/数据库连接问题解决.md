# 数据库连接问题解决方案

## 问题描述

API 服务启动后出现数据库连接错误：
```
sqlalchemy.exc.OperationalError: (psycopg2.OperationalError) connection to server at "127.0.0.1", port 5432 failed: Connection refused
```

前端访问 API 时返回 500 错误。

## 问题原因

PostgreSQL Docker 容器虽然在运行，但是**端口映射没有生效**。

通过 `docker inspect dify-postgres` 检查发现：
```json
{"5432/tcp":[]}
```

端口映射为空数组，说明容器的 5432 端口没有映射到主机的 5432 端口。

## 解决方案

### 1. 停止所有 Docker 服务
```bash
docker-compose -f docker-compose.dev.yaml down
```

### 2. 重新启动 Docker 服务
```bash
docker-compose -f docker-compose.dev.yaml up -d
```

这会重新创建容器并应用 `docker-compose.dev.yaml` 中的端口映射配置：
```yaml
postgres:
  ports:
    - "5432:5432"  # 将容器的 5432 端口映射到主机的 5432 端口
```

### 3. 验证端口映射
```bash
docker ps
```

输出应该显示：
```
CONTAINER ID   IMAGE                  PORTS                              NAMES
7804151f9b82   postgres:15-alpine     0.0.0.0:5432->5432/tcp            dify-postgres
```

### 4. 重启 API 服务

停止旧的 API 进程并重新启动：
```bash
# 在 api 目录下
uv run flask run --host 0.0.0.0 --port=5001 --debug
```

## 验证结果

API 日志显示正常启动，没有数据库连接错误：

## 下一步

现在可以通过 Dify Web UI (http://localhost:3000) 安装 FileBay 插件了：

1. 访问 http://localhost:3000
2. 进入插件管理页面
3. 上传 `filebay_plugin.difypkg` 文件
4. 配置插件参数：
   - FileBay URL: https://uat-filebay.cheersai.cloud
   - Access Token: (需要从 FileBay 生成)
   - Repository Owner: (你的用户名)
   - Repository Name: workspace
   - Branch Name: main
5. 在 Agent 中使用插件的三个工具：
   - read_file: 从 FileBay 读取文件
   - write_file: 写入文件到 FileBay
   - list_files: 列出 FileBay 中的文件
