# 插件打包目录结构问题解决

## 问题描述

安装插件时出现错误：
```
PluginDaemonBadRequestError: read provider: is a directory
```

## 问题原因

使用 `python -m zipfile` 打包时，命令：
```bash
python -m zipfile -c plugin.difypkg manifest.yaml provider/ tools/ ...
```

会将 `provider/` 和 `tools/` 作为**目录条目**添加到 zip 文件中，而不是保持正确的目录结构。

查看错误的 zip 结构：
```
manifest.yaml          # ✅ 正确
main.py                # ✅ 正确
filebay.yaml           # ❌ 错误：应该在 provider/ 目录下
filebay.py             # ❌ 错误：应该在 provider/ 目录下
read_file.yaml         # ❌ 错误：应该在 tools/ 目录下
...
```

## 正确的插件结构

Dify 插件包应该有以下结构：
```
filebay_plugin.difypkg (zip 文件)
├── manifest.yaml
├── main.py
├── requirements.txt
├── provider/
│   ├── filebay.yaml
│   └── filebay.py
├── tools/
│   ├── read_file.yaml
│   ├── read_file.py
│   ├── write_file.yaml
│   ├── write_file.py
│   ├── list_files.yaml
│   └── list_files.py
└── _assets/
    └── icon.svg
```

## 解决方案

### 方案 1：使用 PowerShell Compress-Archive（推荐）

```powershell
cd filebay_plugin
Compress-Archive -Path manifest.yaml,main.py,requirements.txt,provider,tools,_assets -DestinationPath filebay_plugin.difypkg -Force
```

这个命令会**正确保持目录结构**。

### 方案 2：使用 Python zipfile 模块（需要指定每个文件）

```bash
cd filebay_plugin
python -m zipfile -c filebay_plugin.difypkg \
  manifest.yaml \
  main.py \
  requirements.txt \
  provider/filebay.yaml \
  provider/filebay.py \
  tools/read_file.yaml \
  tools/read_file.py \
  tools/write_file.yaml \
  tools/write_file.py \
  tools/list_files.yaml \
  tools/list_files.py \
  _assets/icon.svg
```

但这种方式需要列出每个文件，且**仍然不能正确保持目录结构**。

### 方案 3：使用 zip 命令（Linux/Mac/Git Bash）

```bash
cd filebay_plugin
zip -r filebay_plugin.difypkg manifest.yaml main.py requirements.txt provider/ tools/ _assets/
```

## 修复结果

- ✅ 使用 `Compress-Archive` 重新打包
- ✅ 验证目录结构正确
- ✅ 文件大小：11,508 字节
- ✅ 更新时间：2026-05-10 19:32:47

## 关键要点

1. **不要使用** `python -m zipfile -c plugin.zip manifest.yaml provider/ tools/`
   - 这会将目录作为条目添加，而不是保持结构

2. **推荐使用** PowerShell 的 `Compress-Archive`
   - 在 Windows 上正确保持目录结构
   - 语法简单，不易出错

3. **验证打包结果**
   - 使用 `python -m zipfile -l` 查看内容
   - 确保文件路径包含正确的目录前缀
