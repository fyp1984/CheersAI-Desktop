# FileBay 文件上传功能 - 最终测试指南

## 🎯 测试目标

验证 FileBay 文件可以：
1. 从 FileBay 选择
2. 上传到 Dify
3. 在聊天中显示
4. 被工作流识别和处理

## ✅ 前置条件

### 1. 服务状态检查
- ✅ 前端运行在 http://localhost:3000
- ✅ 后端运行在 http://localhost:9000
- ✅ Docker 服务正常（PostgreSQL, Redis, Weaviate）

### 2. FileBay 配置
确保已配置 FileBay 设置：
1. 登录系统
2. 点击右上角头像 → "设置"
3. 找到 "Gitea 设置" 或 "FileBay 设置"
4. 填写：
   - Gitea URL
   - Owner
   - Repository
   - Token
   - Branch (可选)

## 🧪 测试步骤

### 测试 1: 文件选择器基本功能

#### 步骤：
1. 打开任意聊天应用
2. 点击输入框旁的文件上传按钮（📎）
3. 点击 "从 FileBay 选择"

#### 预期结果：
- ✅ 弹出 FileBay 文件选择器
- ✅ 显示当前路径（默认 "/"）
- ✅ 显示目录列表（文件夹图标）
- ✅ 显示文件列表（文件图标 + 大小）

#### 如果失败：
- 检查浏览器控制台是否有错误
- 检查 FileBay 配置是否完整
- 查看后端日志

---

### 测试 2: 目录导航

#### 步骤：
1. 在文件选择器中点击任意目录
2. 观察目录内容
3. 点击左上角的返回按钮

#### 预期结果：
- ✅ 进入目录后显示该目录的文件
- ✅ 路径显示更新
- ✅ 返回按钮可用
- ✅ 点击返回后回到上级目录

---

### 测试 3: 文件选择和上传

#### 步骤：
1. 在文件选择器中点击一个文件
2. 观察文件是否被高亮
3. 点击"确认"按钮
4. 观察上传过程

#### 预期结果：
- ✅ 文件被高亮选中
- ✅ 底部显示 "已选择: 文件名"
- ✅ "确认"按钮变为可用
- ✅ 点击确认后：
  - 文件选择器关闭
  - 显示 "文件 XXX 上传成功" 提示
  - 文件出现在聊天输入框下方
  - 显示文件名和大小

#### 如果失败：
**错误提示 "上传文件失败: Missing required FileBay credentials"**
- 检查 FileBay 配置是否完整
- 确认所有必填字段都已填写

**错误提示 "上传文件失败: File not found"**
- 文件可能已被删除
- 尝试选择其他文件

**错误提示 "上传文件失败: File size exceeds limit"**
- 文件太大
- 选择较小的文件

**错误提示 "上传文件失败: Unknown error"**
- 查看浏览器控制台详细错误
- 查看后端日志

## 🔍 调试信息

### 浏览器控制台
按 F12 打开开发者工具，查看：

**成功的请求**：
```
POST /console/api/filebay/upload-file
Status: 200 OK
Response: {
  id: "...",
  name: "file.txt",
  size: 1234,
  mime_type: "text/plain",
  url: "...",
  ...
}
```

**失败的请求**：
```
POST /console/api/filebay/upload-file
Status: 400/404/500
Response: {
  error: "错误信息"
}
```

### 后端日志
查看后端终端输出：

**成功的日志**：
```
[FileBay API] ===== LIST FILES REQUEST =====
[FileBay API] Path: /
[FileBay API] User: user@example.com
[FileBay API] Found 5 directories and 10 files

[FileBay API] Uploading file: documents/report.pdf
[FileBay API] Successfully uploaded file: report.pdf (ID: abc123...)
```

**失败的日志**：
```
[FileBay API] Missing required FileBay credentials
[FileBay API] File not found: invalid/path.txt
[FileBay API] Error processing file: ...
```

### 网络请求
在开发者工具的 Network 标签中查看：

1. **列出文件**：
   - URL: `/console/api/filebay/list-files?path=`
   - Method: GET
   - Status: 200
   - Response: 文件列表

2. **上传文件**：
   - URL: `/console/api/filebay/upload-file`
   - Method: POST
   - Status: 200
   - Request: `{ file_path: "..." }`
   - Response: 文件信息
