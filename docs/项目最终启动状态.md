### 插件功能
- **read_file**：从 FileBay 读取文件

### 安装步骤

1. 访问 http://localhost:3000
2. 登录系统
3. 进入**插件管理**页面
4. 上传 `filebay_plugin.difypkg`
5. 配置插件凭证：
   - FileBay URL: `https://uat-filebay.cheersai.cloud`
   - Access Token: （从 FileBay 生成）
   - Repository Owner: （你的用户名）
   - Repository Name: `workspace`
   - Branch Name: `main`

### 使用插件

1. 创建一个 **Agent 类型**的应用（不是 Chatbot 或 Workflow）
2. 在 Agent 中添加 FileBay 工具
3. 通过对话让 Agent 调用工具：
   - "帮我读取 README.md 文件"
   - "列出所有文件"
   - "创建一个 test.txt 文件"
