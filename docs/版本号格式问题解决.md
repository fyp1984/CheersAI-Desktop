# 插件版本号格式问题解决

## 问题描述

安装插件时出现错误：
```
ValueError: Error loading plugin configuration: 1 validation error for PluginConfiguration
meta.runner.version
Input should be a valid string [type=string_type, input_value=3.12, input_type=float]
```

## 问题原因

在 `manifest.yaml` 中，Python 版本号写成了：
```yaml
runner:
  language: python
  version: 3.12  # ❌ YAML 会将 3.12 解析为浮点数
  entrypoint: main
```

YAML 解析器会将 `3.12` 解析为浮点数（float），但 Dify 插件系统要求 `version` 字段必须是字符串类型。

## 解决方案

将版本号用引号括起来，明确指定为字符串：
```yaml
runner:
  language: python
  version: "3.12"  # ✅ 用引号括起来，确保是字符串
  entrypoint: main
```

## 修复步骤

1. 修改 `filebay_plugin/manifest.yaml` 文件
2. 重新打包插件：
   ```bash
   cd filebay_plugin
   python -m zipfile -c ../filebay_plugin.difypkg manifest.yaml provider/ tools/ main.py _assets/ requirements.txt
   ```

## YAML 数字解析规则

在 YAML 中，以下值会被解析为数字：
- `3.12` → 浮点数 3.12
- `3` → 整数 3
- `"3.12"` → 字符串 "3.12"
- `"3"` → 字符串 "3"

对于版本号、端口号等看起来像数字但实际应该是字符串的值，**必须用引号括起来**。

## 其他需要注意的字段

在 Dify 插件的 manifest.yaml 中，以下字段也可能需要用引号：
- `version: "0.0.1"` - 插件版本
- `meta.version: "0.0.1"` - 元数据版本
- `meta.runner.version: "3.12"` - Python 版本
- 任何看起来像数字的配置值
