# Vault 集成架构图

## 整体架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                           用户操作                                    │
│                                                                       │
│  1. 用户登录 Desktop                                                  │
│  2. Desktop 获取 FileBay 配置                                         │
│  3. Desktop 推送配置到 Vault                                          │
│  4. Vault 保存配置到数据库                                            │
│  5. Vault 使用配置进行文件脱敏                                        │
└─────────────────────────────────────────────────────────────────────┘
```

## 详细流程图

```
┌──────────────┐
│   用户登录    │
│   Desktop    │
└──────┬───────┘
       │
       ▼
┌──────────────────────────────────────────────────────────────┐
│  Desktop Web (React/TypeScript)                               │
│                                                               │
│  1. 调用 autoSyncToVault()                                    │
│  2. 检查 Vault 是否运行                                        │
│     GET /console/api/vault/health                            │
└──────┬───────────────────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────────────────────────┐
│  Desktop API (Python/Flask)                                   │
│                                                               │
│  1. 接收健康检查请求                                           │
│     GET /console/api/vault/health                            │
│  2. 转发到 Vault API                                          │
│     GET http://localhost:7788/api/v1/health                  │
│                                                               │
│  3. 接收同步请求                                              │
│     POST /console/api/vault/sync-config                      │
│  4. 获取用户 FileBay 配置                                      │
│     resolve_user_filebay_config(user_email)                  │
│  5. 推送到 Vault API                                          │
│     POST http://localhost:7788/api/v1/filebay/config         │
└──────┬───────────────────────────────────────────────────────┘
       │
       │ HTTP POST
       │ {
       │   "url": "https://uat-filebay.cheersai.cloud",
       │   "username": "user123",
       │   "repo_name": "workspace",
       │   "email": "user@example.com",
       │   "token": "abc123...",
       │   "downloaded_at": "2024-01-01T00:00:00Z",
       │   "version": "1.0"
       │ }
       │
       ▼
┌──────────────────────────────────────────────────────────────┐
│  Vault API Server (Rust/Warp)                                 │
│                                                               │
│  监听: http://127.0.0.1:7788                                  │
│                                                               │
│  接口:                                                        │
│  - GET  /api/v1/health           健康检查                     │
│  - POST /api/v1/filebay/config   保存配置                     │
│  - GET  /api/v1/filebay/config   获取配置                     │
│  - DELETE /api/v1/filebay/config 删除配置                     │
│                                                               │
│  处理流程:                                                     │
│  1. 接收 HTTP 请求                                            │
│  2. 解析 JSON 数据                                            │
│  3. 调用数据库服务                                            │
│  4. 返回 JSON 响应                                            │
└──────┬───────────────────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────────────────────────┐
│  Vault 数据库服务 (Rust/SQLx)                                  │
│                                                               │
│  数据库: SQLite                                               │
│  位置: %TEMP%\cheersai-vault\cheersai-vault.db               │
│                                                               │
│  表: user_settings                                            │
│  ┌──────────────┬──────────────┬─────────────────────┐       │
│  │ key          │ value        │ updated_at          │       │
│  ├──────────────┼──────────────┼─────────────────────┤       │
│  │filebay_config│ JSON 字符串  │ 2024-01-01 00:00:00 │       │
│  └──────────────┴──────────────┴─────────────────────┘       │
│                                                               │
│  操作:                                                        │
│  - save_setting("filebay_config", json_string)               │
│  - get_setting("filebay_config")                             │
│  - delete_setting("filebay_config")                          │
└──────────────────────────────────────────────────────────────┘
```

## 错误处理流程

```
┌─────────────┐
│  用户操作   │
└──────┬──────┘
       │
       ▼
┌──────────────────┐
│ Desktop 检查     │
│ Vault 是否运行   │
└──────┬───────────┘
       │
       ├─ 是 ──────────────────────────────┐
       │                                    │
       │                                    ▼
       │                          ┌──────────────────┐
       │                          │ 调用 Vault API   │
       │                          └────────┬─────────┘
       │                                   │
       │                                   ├─ 成功 ──> 显示成功消息
       │                                   │
       │                                   └─ 失败 ──> 显示错误消息
       │                                                (不影响登录)
       │
       └─ 否 ──> 跳过同步
                 (不影响登录)
```

## 总结

这个架构设计的核心优势:

1. **解耦**: Desktop 和 Vault 通过 HTTP API 通信
2. **安全**: 只在本地通信，不对外暴露
3. **可靠**: 错误不影响用户登录
4. **可扩展**: 易于添加新功能
5. **可测试**: 每个组件可独立测试
