# FileBay 文件选择器使用说明

## ✅ 已完成的工作

FileBay 文件选择器已经完全集成到 Dify 系统中，包括：

1. **前端组件** - 文件浏览和选择界面
2. **后端 API** - 文件列表和内容读取接口
3. **系统集成** - 在所有聊天输入框可用
4. **配置读取** - 自动读取用户的 FileBay 配置

## 🚀 如何使用

### 第一步：登录系统

确保您已经登录到 Dify 系统。如果没有登录，请先登录。

### 第二步：配置 FileBay 凭证

在使用文件选择器之前，您需要先配置 FileBay 凭证：

1. 点击右上角的用户头像
2. 选择 **账户设置**
3. 找到 **Gitea 设置** 标签页
4. 填写以下信息：
   - **FileBay 服务器地址**: 您的 FileBay 实例地址（例如：`https://uat-filebay.cheersai.cloud`）
   - **仓库所有者**: 仓库所有者用户名（例如：`cheersai`）
   - **仓库名称**: 仓库名称（例如：`file-storage`）
   - **API Token**: 您的 FileBay 访问令牌
5. 点击 **保存配置**

**注意**：系统会自动读取您保存的配置，无需额外设置。

### 第三步：使用文件选择器

配置完成后，您可以在任何聊天界面使用 FileBay 文件选择器：

1. **打开聊天界面**
   - 进入任何应用的聊天页面
   - 或者在探索页面与应用对话

2. **点击附件按钮**
   - 在聊天输入框右侧找到附件图标（📎）
   - 点击附件图标

3. **浏览 FileBay 文件**
   - 自动打开 FileBay 文件选择器对话框
   - 查看当前目录的文件和文件夹列表
   - 点击文件夹可以进入子目录
   - 点击左上角的返回按钮可以回到上级目录

4. **选择文件**
   - 点击要上传的文件（文件会高亮显示）
   - 底部会显示已选择的文件名
   - 点击"确认"按钮

5. **文件上传**
   - 文件会自动从 FileBay 读取并上传到 Dify
   - 上传完成后，文件会显示在聊天输入框上方
   - 您可以继续输入消息并发送

## 📋 功能特点

- ✅ **自动配置读取** - 系统自动读取您保存的 FileBay 配置
- ✅ **简洁界面** - 只显示 FileBay 选项，操作简单
- ✅ **目录浏览** - 支持进入子目录和返回上级目录
- ✅ **实时加载** - 从 FileBay 实时读取文件列表
- ✅ **中文界面** - 所有提示信息都是中文
- ✅ **错误提示** - 清晰的错误消息和加载状态
- ✅ **全局可用** - 在所有聊天输入框都可以使用

## ⚠️ 注意事项

1. **必须先登录**
   - 如果没有登录，会提示 401 未授权错误
   - 请先登录系统

2. **必须先配置凭证**
   - 如果没有配置 FileBay 凭证，会提示"Missing required FileBay credentials"
   - 请按照第二步的说明配置凭证

3. **网络连接**
   - 确保您的网络可以访问 FileBay 服务器
   - 如果连接失败，会显示相应的错误消息

4. **文件权限**
   - 确保您的 API Token 有读取仓库的权限
   - 如果权限不足，会显示 404 或权限错误

5. **文件大小**
   - 大文件可能需要较长的加载时间
   - 请耐心等待加载完成

## 🔧 故障排除

### 问题：显示 401 未授权错误

**解决方案**：
- 确认您已经登录系统
- 如果已登录，尝试刷新页面
- 如果问题持续，尝试重新登录

### 问题：点击附件按钮没有反应

**解决方案**：
- 刷新页面重试
- 检查浏览器控制台是否有错误
- 确认前端服务正在运行

### 问题：显示"Missing required FileBay credentials"

**解决方案**：
- 进入账户设置 → Gitea 设置
- 确保所有必填字段都已填写：
  - FileBay 服务器地址
  - 仓库所有者
  - 仓库名称
  - API Token
- 保存后刷新页面

### 问题：显示"Directory not found"或"File not found"

**解决方案**：
- 检查仓库名称是否正确
- 确认文件路径存在
- 检查 API Token 是否有效
- 确认您有访问该仓库的权限

### 问题：文件列表加载失败

**解决方案**：
- 检查 FileBay 服务器地址是否正确
- 确认网络连接正常
- 检查 API Token 权限
- 在 Gitea 设置页面点击"测试连接"按钮
- 查看后端日志获取详细错误信息

### 问题：文件上传失败

**解决方案**：
- 检查文件大小是否超过限制
- 确认文件类型是否支持
- 检查网络连接是否稳定
- 查看浏览器控制台错误信息

## 📊 API 端点

系统提供了以下 API 端点（供开发参考）：

### 1. 列出文件
```
GET /console/api/filebay/list-files?path={directory_path}
```
**说明**: 列出指定目录中的文件和文件夹

### 2. 读取文件
```
POST /console/api/filebay/read-file
Body: {"file_path": "path/to/file"}
```
**说明**: 读取指定文件的内容

### 3. 下载文件
```
GET /console/api/filebay/download-file?path={file_path}
```
**说明**: 下载指定文件

## 🔐 配置管理

### 配置存储位置

您的 FileBay 配置存储在：
- **数据库**: 用户账户的 `custom_config` 字段
- **环境变量**: `.env` 文件（作为备份）

### 配置优先级

系统按以下优先级读取配置：
1. 用户账户配置（数据库）
2. 环境变量（.env 文件）

### 配置字段

- `gitea_url` / `filebay_url`: FileBay 服务器地址
- `gitea_owner` / `filebay_owner`: 仓库所有者
- `gitea_repo` / `filebay_repo`: 仓库名称
- `gitea_token` / `filebay_token`: API Token
- `filebay_branch`: 分支名称（默认：main）
