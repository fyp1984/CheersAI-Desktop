## 📦 安装步骤

### 方法 1：通过 Web 界面安装（推荐）

1. **打开 Dify 管理后台**
   - 访问：http://localhost:3000
   - 使用管理员账号登录

2. **进入插件管理**
   - 点击左侧菜单 "工作空间设置"
   - 选择 "插件" 标签

3. **上传插件**
   - 点击 "安装插件" 或 "上传插件" 按钮
   - 选择文件：`E:\CheersAI-Desktop\filebay_plugin.difypkg`
   - 等待上传和安装完成

4. **配置插件凭据**
   - 在插件列表中找到 "FileBay Sync"
   - 点击 "配置" 或 "设置" 按钮
   - 填写以下信息：

   ```
   FileBay URL: https://uat-filebay.cheersai.cloud
   Access Token: [你的 FileBay Token]
   Repository Owner: [你的用户名]
   Repository Name: workspace
   Branch Name: main
   ```

5. **验证配置**
   - 点击 "验证" 按钮测试连接
   - 如果成功，点击 "保存"

## 🔑 获取 FileBay Access Token

### 方式 1：通过 FileBay Web 界面

1. 登录 FileBay：https://uat-filebay.cheersai.cloud
2. 点击右上角头像 → "设置"
3. 左侧菜单选择 "应用" → "访问令牌"
4. 点击 "生成新令牌"
5. 填写：
   - 令牌名称：`dify-plugin`
   - 权限：
     - ✅ `read:repository`
     - ✅ `write:repository`
6. 点击 "生成令牌"
7. **立即复制令牌**（只显示一次！）

### 方式 2：使用现有配置

如果你已经在系统中配置了 FileBay，可以从数据库获取：

```python
# 在 Python 环境中执行
```

## 🚀 使用插件

### 在 Agent 中使用

1. **创建新的 Agent 应用**
   - 进入 "应用" 页面
   - 点击 "创建应用"
   - 选择 "Agent" 类型

2. **启用插件**
   - 在应用设置中找到 "工具"
   - 搜索 "FileBay Sync"
   - 启用该插件的所有工具：
     - ✅ Read File
     - ✅ Write File
     - ✅ List Files

3. **测试对话**

   ```
   用户: 请列出仓库中的所有文件
   Agent: [自动调用 list_files 工具并返回结果]
   
   用户: 读取 README.md 文件的内容
   Agent: [自动调用 read_file 工具并显示内容]
   
   用户: 创建一个新文件 test.txt，内容是 "Hello from Dify!"
   Agent: [自动调用 write_file 工具并确认创建]
   ```

### 在 Workflow 中使用

1. **创建 Workflow 应用**
   - 选择 "Workflow" 类型

2. **添加工具节点**
   - 拖拽 "工具" 节点到画布
   - 选择 "FileBay Sync" → "read_file"
   - 配置参数：
     - file_path: `README.md`
     - encoding: `utf-8`

3. **连接其他节点**
   - 可以连接 LLM 节点处理文件内容
   - 可以连接其他工具节点

## ❓ 常见问题

### Q1: 插件安装失败

**A**: 
- 检查 Dify 版本（需要 1.0+）
- 查看浏览器控制台错误
- 检查 Dify API 日志：`docker logs dify-api`

### Q2: 无法连接到 FileBay

**A**:
- 确认 FileBay URL 正确且可访问
- 检查 Access Token 是否有效
- 验证网络连接
- 查看插件日志

### Q3: 文件读取返回 404

**A**:
- 确认文件路径正确（相对于仓库根目录）
- 使用 list_files 工具查看实际目录结构
- 检查分支名称是否正确

### Q4: 文件写入失败

**A**:
- 确认 Token 有写入权限
- 检查目标路径格式
- 确认分支存在且可写入
- 查看提交信息是否为空
